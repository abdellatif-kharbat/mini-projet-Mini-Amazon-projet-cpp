# 🛒 Mini Amazon - C++ Console Application

## 📌 Description

This project is a **console-based application written in C++** that simulates a simplified version of an e-commerce platform similar to Amazon.

The application allows users to manage products, simulate purchases, and interact with a basic shopping system using object-oriented programming (OOP) principles.

---

## 🎯 Objectives

* Apply **Object-Oriented Programming (OOP)** concepts in C++
* Practice working with:

  * Classes and objects
  * File handling
  * Data structures
* Build a simple but functional **e-commerce simulation system**

---

## ⚙️ Features

* 📦 Product management (add, display, search)
* 🛍️ Shopping functionality (select and buy products)
